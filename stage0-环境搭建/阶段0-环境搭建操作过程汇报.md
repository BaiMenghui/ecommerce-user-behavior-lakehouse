#### 3.2.2 Hive Metastore 部署

- **镜像：** apache/hive:3.1.3
- **容器名：** hive-metastore
- **端口：** 9083 (Thrift)
- **依赖：** PostgreSQL

**部署命令（docker-compose.yml 中定义）：**
```yaml
hive-metastore:
  image: apache/hive:3.1.3
  container_name: hive-metastore
  depends_on:
    - postgres
  environment:
    SERVICE_NAME: metastore
    METASTORE_DB_HOST: postgres
    METASTORE_DB_PORT: 5432
    METASTORE_DB_NAME: metastore_db
    METASTORE_DB_USER: hive
    METASTORE_DB_PASSWORD: hive123
  ports:
    - "9083:9083"
```

**验证结果：**
```bash
# 容器状态检查
docker ps | grep hive-metastore
# hive-metastore  apache/hive:3.1.3  Up 43 minutes  0.0.0.0:9083->9083/tcp ✅
```

> **说明：** Hive Metastore 服务正常运行，Spark 可以通过 thrift://localhost:9083 连接。
> 由于 Hive Metastore 的默认 warehouse 路径（/opt/hive/data/warehouse）在容器内，
> 本地 Spark 写入时会有权限问题。解决方案：使用本地 warehouse 目录进行开发，
> 或者将 warehouse 目录挂载到共享卷。本项目采用本地 warehouse 目录方案。

#### 3.3.4 问题与解决方案

**问题1：Table not found: test_hudi_cow**
- **现象：** 直接执行 INSERT INTO test_hudi_cow 报错表不存在
- **原因：** 没有先执行 CREATE TABLE 建表，就直接插入数据
- **解决方案：** 按照正确顺序操作 —— 先 CREATE TABLE，再 INSERT

**问题2：Mkdirs failed to create /opt/hive/data/warehouse/...**
- **现象：** 连接 Hive Metastore 后写入数据时报权限错误
- **原因：** Hive Metastore 默认 warehouse 路径在容器内，本地 Spark 无写入权限
- **解决方案：** 使用本地 warehouse 目录，配置 `spark.sql.warehouse.dir=~/hudi-bigdata/warehouse`

**问题3：Python 3.14 与 PySpark 3.3 兼容性问题**
- **现象：** 使用 PySpark Python API 时报 `ModuleNotFoundError: No module named 'typing.io'`
- **原因：** Python 3.14 移除了 typing.io，PySpark 3.3 不兼容
- **解决方案：** 使用 spark-sql 命令行方式（Scala/Java 实现），不受 Python 版本影响
