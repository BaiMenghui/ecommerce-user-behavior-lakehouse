❌ **问题点：**

- **原因：没有先创建表就直接插入数据了**

---

## 问题解决方法

### 错误原因
你直接执行了 INSERT 语句，但表 `test_hudi_cow` 还没有创建。

### 正确顺序
```
1. 启动 Spark SQL（带 Hudi 配置）
2. CREATE TABLE 建表 ← 你漏掉了这一步！
3. INSERT INTO 插入数据
4. SELECT 查询验证
5. UPDATE / DELETE 验证增删改查
```

## 完整操作步骤

### 第一步：启动基础服务（已完成，确认状态）

```bash
# 进入项目目录
cd ~/hudi-bigdata

# 启动服务
docker compose up -d

# 查看服务状态
docker compose ps
```

### 第二步：下载 Hudi Bundle Jar

```bash
# 创建 jars 目录
mkdir -p ~/hudi-bigdata/jars

# 下载 Hudi Spark Bundle（Spark 3.3 对应版本）
cd ~/hudi-bigdata/jars
wget https://repo1.maven.org/maven2/org/apache/hudi/hudi-spark3.3-bundle_2.12/0.14.1/hudi-spark3.3-bundle_2.12-0.14.1.jar
```

> 如果下载慢，可以用迅雷下载后放到 WSL 的 `~/hudi-bigdata/jars/` 目录

### 第三步：启动 Spark SQL（带 Hudi 配置）

```bash
# 方式一：使用脚本启动（推荐）
chmod +x ~/hudi-bigdata/scripts/start-spark-sql.sh
~/hudi-bigdata/scripts/start-spark-sql.sh

# 方式二：手动启动
spark-sql \
    --master local[2] \
    --jars ~/hudi-bigdata/jars/hudi-spark3.3-bundle_2.12-0.14.1.jar \
    --conf spark.sql.warehouse.dir=/tmp/spark-warehouse \
    --conf spark.hadoop.hive.metastore.uris=thrift://localhost:9083 \
    --conf spark.sql.catalog.spark_catalog=org.apache.spark.sql.hudi.catalog.HoodieCatalog \
    --conf spark.serializer=org.apache.spark.serializer.KryoSerializer \
    --conf spark.sql.extensions=org.apache.spark.sql.hudi.HoodieSparkSessionExtension
```

### 第四步：建表并验证（关键步骤！）

进入 spark-sql 后，**先建表再插入数据**：

```sql
-- 1. 创建 Hudi COW 表
CREATE TABLE IF NOT EXISTS test_hudi_cow (
    id STRING,
    name STRING,
    age INT,
    ts BIGINT
) USING hudi
OPTIONS (
    type = 'cow',
    primaryKey = 'id',
    preCombineField = 'ts',
    hoodie.table.name = 'test_hudi_cow'
);

-- 2. 验证表创建成功
SHOW TABLES;

-- 3. 插入数据
INSERT INTO test_hudi_cow VALUES
    ('id001', 'zhangsan', 20, 1750000000000),
    ('id002', 'lisi', 22, 1750000000001);

-- 4. 查询验证
SELECT * FROM test_hudi_cow;
```

### 第五步：执行完整验证脚本

```sql
-- 在 spark-sql 中执行完整验证脚本
source ~/hudi-bigdata/sql/hudi_basic_verification.sql;
```

## 快速验证命令清单

在 spark-sql 中依次执行以下命令，验证增删改查：

```sql
-- 1. 建表
CREATE TABLE test_hudi_cow (id STRING, name STRING, age INT, ts BIGINT) USING hudi OPTIONS (type='cow', primaryKey='id', preCombineField='ts');

-- 2. 增
INSERT INTO test_hudi_cow VALUES ('id001','zhangsan',20,1750000000000), ('id002','lisi',22,1750000000001);

-- 3. 查
SELECT * FROM test_hudi_cow;

-- 4. 改（相同主键再次插入即为更新）
INSERT INTO test_hudi_cow VALUES ('id001','zhangsan',21,1750000000010);
SELECT * FROM test_hudi_cow WHERE id='id001';

-- 5. 删
DELETE FROM test_hudi_cow WHERE id='id002';
SELECT * FROM test_hudi_cow;
```

## 常见问题

### Q1: Table not found 错误
**原因：** 没有先 CREATE TABLE 就直接 INSERT
**解决：** 先执行 CREATE TABLE 语句创建表

### Q2: Hudi 类找不到
**原因：** 没有正确加载 Hudi Bundle Jar
**解决：** 启动 spark-sql 时加上 `--jars /path/to/hudi-spark3.3-bundle_2.12-0.14.1.jar`

### Q3: 连不上 Hive Metastore
**原因：** Hive Metastore 服务没启动或端口不对
**解决：** 用 `docker ps` 确认 hive-metastore 容器在运行，检查 9083 端口

### Q4: Spark 命令找不到
**原因：** Spark 没有安装或环境变量没配置
**解决：** 需要先安装 Apache Spark 3.3.x 并配置环境变量
