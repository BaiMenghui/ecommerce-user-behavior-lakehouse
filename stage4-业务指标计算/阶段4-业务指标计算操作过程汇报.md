## 三、步骤 2：创建 ADS 结果表

### 3.1 设计原则

| 设计项 | 决策 | 理由（适配大屏高并发查询） |
|---|---|---|
| 表结构 | 扁平宽表、一行一结果，**无嵌套、无 join 才能取数** | 前端一次点查直接出图 |
| 表类型 | Hudi COW | 读多写少（每日一批），读性能优先 |
| 预聚合 | 比率、占比、GMV 在 ADS **先算好存列**，前端不做二次计算 | 口径唯一来源固化在 ADS |
| 粒度 | dau_trend / funnel：一行一天；topn：一行一商品；share：一行一类目；heatmap：一行一小时 | 与图表一一对应 |
| 分区 / 主键 | dt 分区；主键= dt / item_id / category_id / hour_of_day | 分区内唯一，重跑幂等 |

- 模拟单价：`pmod(hash(item_id), 450) + 50`，与口径文档条款 1、校验脚本三方一致

### 4.2 核心代码片段（完整见脚本文件）

```python
# 1. DAU趋势 + GMV + 客单价（三段来源 CROSS JOIN 成一行）
dau_df = spark.sql(f"""
    SELECT u.dau, u.new_user_cnt, u.new_user_ratio,
           u.pv_cnt, u.buy_cnt, u.action_cnt,
           b.paying_user_cnt,
           u.buy_cnt AS order_cnt,
           ROUND(g.gmv, 2) AS gmv,
           CASE WHEN b.paying_user_cnt > 0
                THEN ROUND(g.gmv / b.paying_user_cnt, 2) ELSE 0 END AS avg_ticket,
           '{dt}' AS dt
    FROM (SELECT COUNT(*) AS dau, ... FROM dws_user_action_day WHERE dt='{dt}') u
    CROSS JOIN (SELECT COUNT(DISTINCT user_id) AS paying_user_cnt
                FROM dwd_user_behavior_fact
                WHERE dt='{dt}' AND behavior_type='buy') b
    CROSS JOIN (SELECT SUM(buy_cnt * (pmod(hash(item_id), 450) + 50)) AS gmv
                FROM dws_item_action_day WHERE dt='{dt}') g
""")

# 3. 热销Top10：buy_cnt 降序，平分时 action_cnt 降序、item_id 升序（确定性排名）
ROW_NUMBER() OVER (ORDER BY buy_cnt DESC, action_cnt DESC, item_id ASC) ... WHERE rank_no <= 10

# 5. 时段热力：DWD 直通例外（口径条款5）
SELECT hour_of_day, COUNT(*) AS action_cnt, ...
FROM dwd_user_behavior_fact WHERE dt='{dt}' GROUP BY hour_of_day
```

## 七、踩坑与注意事项

1. **模拟单价必须确定性**：用 `pmod(hash(item_id),450)+50` 而非随机数，保证 ETL 重跑、校验复算、论文实验三处 GMV 完全一致；
2. **除零保护**：所有比率类指标 `CASE WHEN 分母>0 THEN ... ELSE 0`，漏斗/客单价均适用；
3. **占比容差**：类目占比逐行 ROUND 后求和可能为 99.99~100.01，校验用 0.5 容差而非严格相等；
4. **TopN 确定性**：并列时用 action_cnt、item_id 依次破平，避免 Spark shuffle 顺序不稳定导致两次跑名次不同；
5. **paying_user_cnt 直查 DWD**：购买用户数必须去重到「人」，不能 Σdws_item.buy_user_cnt（用户买多件会被重复计数）；
6. **CSV 导出用 coalesce(1)**：单文件便于前端/W8 服务层直接读取；导出在全部算完后执行，保证是全量快照。
