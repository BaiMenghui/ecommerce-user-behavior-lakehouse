## 进行中：Hudi vs Hive 存储模式性能对比（规划表阶段 7 核心实验）

**实验设计**（对应开题报告创新实验）：

1. **对照组**：Hive 分区表（基线） / Hudi COW 表 / Hudi MOR 表，三组数据量与分区完全一致
2. **查询场景**：用户行为统计聚合、商品销售 Top-N、按 dt 分区增量查询、全量覆写 vs Upsert 增量写入
3. **控变量**：相同 SQL、固定 Spark 资源配置，每轮重复三次取均值、剔除冷启动首轮，唯一变量为表类型
4. **预期**：查询耗时相对 Hive 基线降低 30% 以上（设计预期 COW≈0.84x、MOR≈0.70x，实际以实验报告为准）
