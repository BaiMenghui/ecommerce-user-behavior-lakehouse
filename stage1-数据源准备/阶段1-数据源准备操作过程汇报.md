## 二、数据集概况

### 2.1 数据集基本信息

| 属性 | 说明 |
|------|------|
| **数据集名称** | UserBehavior |
| **来源平台** | 阿里云天池公开数据集（dataId=649） |
| **数据集描述** | 阿里巴巴提供的淘宝用户行为数据集，用于隐式反馈推荐问题研究 |
| **原始完整规模** | 100,150,807 条行为记录，987,994 个用户，4,162,024 个商品 |
| **本次使用规模** | 1,048,576 条记录（约100万条抽样子集） |
| **主体时间范围** | 2017年11月25日 ~ 2017年12月3日（9天连续数据） |
| **许可协议** | CC BY-NC-SA 4.0 |

### 2.2 数据集字段说明

| 列名称 | 数据类型 | 说明 |
|--------|----------|------|
| user_id | 整数(int64) | 序列化后的用户ID |
| item_id | 整数(int64) | 序列化后的商品ID |
| category_id | 整数(int64) | 商品类目ID |
| behavior_type | 字符串 | 行为类型：pv / buy / cart / fav |
| timestamp | 整数(int64) | Unix时间戳（秒） |
| datetime_str | 字符串 | 可读日期时间（原始数据附带） |

### 2.3 行为类型说明

| 行为类型 | 含义 | 业务说明 |
|----------|------|----------|
| pv | 浏览 | 商品详情页PV，等价于点击 |
| fav | 收藏 | 用户收藏商品 |

#### 3.3.1 清洗流程设计

```
原始数据 (UserBehavior.csv, 1,048,576条)
    │
    ├── Step 1: 加载原始数据
    ├── Step 2: 缺失值处理（关键字段缺失则删除该行）
    ├── Step 3: 重复值剔除（全行去重 + 关键字段去重）
    ├── Step 4: 异常值过滤（非法ID、无效行为类型、异常时间戳）

    ├── Step 6: 按日分区存储（dt=YYYY-MM-DD/user_behavior.csv）
    └── Step 7: 生成清洗报告 + 数据验证
```
